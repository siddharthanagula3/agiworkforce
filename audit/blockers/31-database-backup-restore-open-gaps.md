# Database backup and restore: open gaps

Lifted on 2026-09-27 from the "Open gaps" section of `docs/runbooks/database-backup-restore.md`. The runbook describes the procedure; this file is what it cannot yet do. Delete a bullet when it is closed, and this file when none is left.

- **No published RPO or RTO.** The only recovery time the repository has measured is the logical drill's, on a container-sized database in CI; that number says nothing about an in-place production restore. The Neon branch drill proves recent production data is recoverable, but it does not measure the outage window or the reconnection time of an in-place restore. Publishing either objective needs a timed incident rehearsal.
- **Object versioning and the backup bucket are not provisioned.** The replication code path is complete and runs hourly, but it replicates nothing until the five `AGI_STORAGE_BACKUP_*` variables are set, and object versioning has to be enabled on both buckets in the storage provider's console or API. Both are founder actions; no further code is needed. Until the variables are set the cron logs an error and answers 503 naming them, so an unconfigured backup shows up as a failing scheduled job rather than a silent success.
- **Restore replay of erasures is not asserted in CI.** The purge cron synchronizes the erasure ledger after each sweep, but the weekly logical-restore CI job does not yet assert that replay re-arms a subject erased before the recovery point. The unit coverage in `apps/web/lib/server/erasure-tombstones.test.ts` proves the replay logic; the live restore drill remains the required promotion evidence.
- **No external uptime monitor calls `/api/health`.** An outage that triggers a restore may be detected only by the existing daily cron in `docs/runbooks/incident-response.md`, not sooner. The same gap is in `32-incident-response-open-gaps.md`.
- **Only Neon has been rehearsed.** Both adapters are proven against local Postgres 17 and the contract suite runs on every host it is pointed at, but a managed host's TLS, pooling and connection ceiling are unmeasured until a real target exists.
