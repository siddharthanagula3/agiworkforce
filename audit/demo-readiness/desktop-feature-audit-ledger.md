# Desktop Feature Audit Ledger

Status: Active
Owner: Desktop lead
Last updated: 2026-06-05

This ledger tracks Desktop demo-readiness one feature group at a time. A row is closed only when the user can perform the scenario in AGI Desktop, the result is visible, errors are understandable, frontend and native paths are traced, focused tests pass, and evidence is recorded.

Allowed statuses: `not-started`, `in-review`, `needs-fix`, `fixed-pending-test`, `blocked-with-evidence`, `closed-with-evidence`.

## Audit Rules

- Audit Desktop only after the current Website wave is closed or intentionally paused with evidence.
- Do not close a Desktop row from code-level tests alone.
- Cross-boundary Tauri IPC changes require frontend and native verification.
- Local, BYOK, and Managed Cloud are separate trust boundaries. Never silently route Local chats, files, tools, or developer sessions to BYOK or Managed Cloud.
- High-risk actions require visible approval and visible scope.
- Reference repos are for behavior comparison only. Do not copy proprietary code or assets.
