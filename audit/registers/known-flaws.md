## How to use this file

Check this register before reporting a bug as new. If the defect is already a row,
update that row rather than opening a second one, and keep its id: commits, audits
and other documents cite these ids by search.

To close an entry, delete its row in the same commit as the fix. Nothing here is
annotated as fixed and left in place, because a reader cannot tell a stale
annotation from a live one, and a closed row that stays gets re-tested by whoever
reads it next. Git history is where a closed flaw stays findable.

The last column names what was read on the day the row was written or last
confirmed. A row whose evidence no longer resolves is not a flaw, it is rot:
delete it.

This register absorbed the audit remediation ledger and the remediation register on
2026-09-07, and both were deleted in the same commit. Items already marked resolved,
and items whose cited file, route or pattern no longer exists, were dropped rather
than copied. Their full text is in git history at the commit before this one.
