# One account, one plan, one ledger: open findings of 2026-10-27

Status: Current
Owner: Platform + billing
Last updated: 2026-10-27

The audit read how web, desktop, mobile, CLI, VS Code and Chrome sign in, learn
their plan, choose a model, call the AI and show usage, against one canonical
account, entitlement resolver and credit ledger. It was code reading on
`origin/main` at `b216b0af12`, with each finding re-read in code before it was
fixed or recorded here. Nothing here was run against a live payment provider,
app store or production database.

The defects fixed in the same engagement are in Git on the branch
`feat/one-product-account-billing` and are not repeated here. Every row below is
open. `V` means the code path was read; `S` means the impact is inferred. Delete
a row in the commit that closes it, and this file when it is empty.
