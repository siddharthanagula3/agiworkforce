## Rules

- Every parity claim needs a source, an AGI path, and a status.
- Do not claim a file or feature is complete unless the evidence entry names the path, owner area, parity relevance, and verification result.
- Do not copy proprietary code. Implement behavior from public docs and original AGI contracts.
- Open-source references can inform architecture; preserve license obligations for any copied material.
- Mark uncertain items as `Unknown`, not `Done`.
