## Cross-cutting signatures

Claude's strongest cross-surface UX signatures, beyond any one feature row:

1. **One composer grammar everywhere.** `+ → input → model dropdown → mic → send`. The visual element budget is identical from a 1480 px desktop window down to a 360 px Chrome side panel; only spacing and labels collapse.
2. **3-tier model picker with capability blurbs.** Opus / Sonnet / Haiku with a one-line "best-for" line and a thinking toggle is reused verbatim across desktop, mobile, Chrome extension and mobile sheets. Free plan greys Opus rather than hiding it.
3. **Permission prompts are surfaced, never hidden.** Every actuating tool call (filesystem, browser, connector write-tools) produces a prompt with the same three resolutions: `Always allow ↩` / `Deny esc` / scope-modifier (`Always allow on this site` etc.). Ask-vs-Act is a top-level concept exposed in the Chrome extension and in the VS Code Modes dropdown.
4. **Tool calls collapsed by default, expanded on click.** A faint left rail of `<Icon> <Tool method> Result` rows terminating in `✓ Done`, with reasoning blocks above and JSON detail one click away. Mobile elevates this to a sheet; desktop keeps it inline.
5. **Connectors are the single integration point.** ~260 connectors in a 19-page directory modal with categories on the left, search/sort/type filters on top, per-tool `Always allow / Ask / Off` toggles per connector, and inline `+ menu → Connectors` submenu access from the composer. MCP servers in CLI reuse the same allow/ask/off vocabulary.
6. **Artifacts open in a right companion pane on big screens, become a tab on mobile.** Same card primitive (file icon + name + Open in <App> + Download all row) across surfaces; layout adapts to width.
7. **Slash-command palette is the universal command surface.** CLI has the deepest palette; desktop hosts the same metaphor for skills; Chrome extension reuses the syntax for user-defined shortcuts.
8. **Plan tiers are mentioned everywhere usage matters.** Free / Pro / Max 5× / Max 20× labels and pricing are identical across the web pricing page, the support article, mobile billing, CLI `/upgrade`, Chrome extension upgrade banner, and VS Code usage-limit sidebar.
