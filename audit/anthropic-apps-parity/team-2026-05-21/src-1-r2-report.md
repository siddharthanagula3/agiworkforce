## Package summary

`@agiworkforce/unified-chat` is the surface-neutral React chat library consumed by desktop, web, mobile-adjacent shared UI, Chrome extension, and VS Code extension surfaces (`packages/unified-chat/README.md:9-17`). It exposes ~120 components, hooks, stores, and library helpers via a single barrel at `src/index.ts:1-324`.

- **Component count discrepancy:** Brief states 68 React components. `find src/components -name '*.tsx'` returns **77** files (excluding `__tests__`). Brief is stale or sample-sized; lead should treat 77 as ground truth as of 2026-05-21.
- **Public API surface:** `src/index.ts` re-exports ~110 named symbols including `ChatInterface` (orchestrator), `ChatStream`, `ChatInput`, `MessageList`, `MessageBubble`, `ModelSelector`, `Sidebar`, `ArtifactRenderer`, `ArtifactsSidebar`, `CommandPalette`, `SettingsModal`, `KeyboardShortcutsDialog`, plus 12 Zustand stores.
- **Notable comment in `index.ts:48-55`:** `ChatInterface` is marked as the _legacy_ top-level orchestrator; every shipping surface (web, desktop) now drives streaming through surface-specific runtime + the lower-level primitives (`ChatStream`, `ChatInput`, `MessageList`). Component still re-exported for back-compat. Dead-code risk.
- **`@agiworkforce/design-tokens`** is two files: `src/index.ts` (330 lines of TypeScript palette/typography/shadow/CSS-var maps for 4 themes: chat-light, chat-dark, extension-light/dark, vscode) and `src/chat.css` (66 lines mirroring the same vars in CSS `@layer base`). It compiles to `dist/` and exposes a `./chat.css` subpath.

**Cross-cutting finding — three coexisting color-token namespaces inside `packages/unified-chat`:**

1. `--chat-*` (canonical, defined by `packages/design-tokens`): `Sidebar.tsx`, `ChatInput.tsx`, `MessageBubble.tsx`, `ModelSelector.tsx`, `EmptyState.tsx`, `AttachmentMenu.tsx`, `ArtifactPanel.tsx`, `ActionBar.tsx`, `UserProfile.tsx`, `ThinkingBlock.tsx`, `WebSearchCard.tsx`, `ConversationItem.tsx` — full set.
2. shadcn-style `hsl(var(--popover))`, `hsl(var(--border))`, `hsl(var(--card))`, `hsl(var(--muted-foreground))`: `SlashCommandMenu.tsx:51,65,77,85,94`, `KeyboardShortcutsDialog.tsx:97,105,108,141-147`, `ChatInputToolbar.tsx:108`.
3. shadcn unprefixed semantic Tailwind classes `bg-muted/50`, `border-border`, `bg-card`, `text-foreground`, `text-muted-foreground`: `ArtifactRenderer.tsx:581,586,594,606,635,679,694`, `ArtifactsSidebar.tsx:58,66,69,79,98,100`, `ToolCallCard.tsx:205,210-228,239,249`, `AgentStepTimeline.tsx:37-49`, `CheckpointManager.tsx` (cn helpers).

Same package, three token vocabularies. Means: light-mode of `Sidebar` works, light-mode of `ArtifactRenderer` and `KeyboardShortcutsDialog` does not (the `--popover`, `--card`, `--muted` vars are never defined in `packages/design-tokens/src/chat.css`). Treated as **P1 design-tokens cohesion gap** in the design-tokens section below.

This is the load-bearing design-tokens cohesion gap (P1, ~3h alias path).
2. **77 components, not 68** (brief was sample-sized or stale). Two parallel artifact UIs (`ArtifactRenderer` + `ArtifactPanel`) and three parallel suggestion surfaces (`QuickChips`, `AdvancedEmptyState`, `PromptSuggestionsDropdown`) — consolidation candidates.
3. **Composer Cmd+Enter to send is inverted from default chat-app convention** (`ChatInput.tsx:161-170`); needs lead verification against Claude image evidence. Drag-drop and paste-image attach are missing (P1, ~6h).
4. **Conversation management is missing from `ConversationItem`** — no rename, delete, pin/unpin, archive UI (P0 if v1 parity demands it).
5. **`SettingsModal` is a 22-line event-dispatch stub**; the package owns no settings UI. Settings parity rolls up to the host audits (`src-2`/`src-3`/`src-4`). `BudgetTracker` token estimator is `chars * 0.25` — replace with provider usage (P1).
6. **Lucide stroke widths are inlined per component** (1.75 in sidebar, 2 elsewhere). No stroke-width token. Likely heavier than Claude (P2, ~3h).
