## Cross-cutting context (read once, applies to every row)

- **Active shell is `DesktopShellV3`** (`apps/desktop/src/features/v3/DesktopShellV3.tsx:46-149`), gated by `FeatureFlagName.DESKTOP_CHAT_V3` (`apps/desktop/src/services/featureFlags.ts:30,204-211`) — default-on with `localOverride(desktop_chat_v3,false)` as emergency kill-switch. App.tsx renders V3 when enabled, falls back to `<ChatInterface>` from `@agiworkforce/unified-chat` when not (`apps/desktop/src/App.tsx:1284-1336`). I treat v3 as current state; v2 (legacy `ChatInputArea`/`ChatStream`/`Sidebar` under `features/chat/`) as the documented fallback, audited where it differs.
- **DesktopShellV3 delegates rendering to `ChatInterface` from `packages/unified-chat` for the chat pane** (`DesktopShellV3.tsx:101-114`). The v3 standalone primitives (`Composer.tsx`, `ActiveChat.tsx`, `ResponseActionRow.tsx`) are exported via `features/v3/index.ts:16-43` but **not instantiated by the shell** — they are dead code on the production path. Authoritative chat input/stream behavior therefore lives in `packages/unified-chat` (src-1 scope).
- **Cowork and Code modes are placeholders** in `DesktopShellV3.tsx:117-145`: literal text "Cowork mode coming" / "Code mode coming" gated by `mode === 'cowork' | 'code'`. The Sidebar exposes the mode switcher (`features/v3/Sidebar.tsx:259-291`). This is an intrinsic gap regardless of Claude parity.
- **Scope adjustments from teammate brief:** `features/billing/` and `features/model-picker/` directories do not exist on disk. Billing lives under `features/pricing/{PlansModal,PlanCard}.tsx` and `features/subscription/{SubscriptionGate,SubscriptionLockDialog}.tsx` plus the v3 file `features/v3/Pricing.tsx`. Model picker lives at `features/chat/{ModelSelectorButton,QuickModelSelector}.tsx`, v3 `features/v3/ModelPopover.tsx`, and the settings `features/settings/ModelSelector.tsx`. I audit those.
