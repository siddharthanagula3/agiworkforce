# AGI Surface Gap Ledger

Last updated: 2026-05-20.

This ledger records the current Anthropic Applications parity state across AGI Workforce surfaces. It is based on direct repo exploration and should be updated whenever a surface audit or implementation slice closes.

## Surface Baseline

AGI Workforce already has first-party surfaces under `apps/`:

| Surface | Path                    | Current role                                                                                                  |
| ------- | ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| CLI     | `apps/cli`              | Rust CLI/TUI and current parity engine foundation.                                                            |
| Desktop | `apps/desktop`          | Tauri desktop app with local data, onboarding, artifacts, MCP, memory, and privacy commands.                  |
| Web     | `apps/web`              | Next.js web app for account, projects, billing, teams, chat APIs, and artifact/chat surfaces.                 |
| Mobile  | `apps/mobile`           | Expo mobile app with local-first v1 posture, privacy/compliance onboarding, imports, and companion workflows. |
| VS Code | `apps/extension-vscode` | IDE extension with agent mode, file reads, patch blocks, checkpoints, and plan mode.                          |
| Chrome  | `apps/extension`        | MV3 browser extension with WebMCP discovery/calls and native bridge support.                                  |
| Sandbox | `apps/sandbox`          | Cross-origin artifact renderer.                                                                               |

Shared contracts live primarily in `packages/`, Rust engine/runtime support in `crates/`, and future managed services in `services/` plus `supabase/`.

## Highest-Impact Gaps To Close Next

1. Define one cross-surface data ownership model for projects, artifacts, memory, teams, and billing.
2. Mount and initialize API gateway `agents` and `mcp` routes, or explicitly mark them private/dead until ready.
3. Replace desktop hook and memory analytics placeholders with real implementations or visible unsupported states.
4. Keep mobile v1 local-first, but design explicit BYOK unlock/fork flow before exposing it.
5. Replace VS Code managed-plan usage stubs with real BYOK/local labels and usage-source reporting.
6. Finish Chrome native host installer automation, including Windows.
7. Fix docs drift: CLI MCP docs must match current transports, desktop onboarding paths must match code, and outdated comments must be cleaned.
