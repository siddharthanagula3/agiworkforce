# Generated QA Reports

Status: Current
Owner: QA/design/platform
Purpose: Short-lived QA evidence from manual, browser, and simulator passes
Retention: Current wave only — archive under docs/archive/ when superseded
Last updated: 2026-06-06

This folder contains generated screenshots from current manual, browser, and
simulator QA passes.

Use these files as short-lived evidence only. Durable conclusions should move
into a dated report, `docs/current`, `docs/plans`, or an audit ledger. When a QA
wave is no longer current, archive the screenshots under `docs/archive/` with a
manifest instead of leaving stale raw captures here.

Rules:

- Keep generated files named by surface, screen, and date or QA wave.
- Do not treat a screenshot as proof unless the related route or screen was
  manually checked after the capture.
- Do not cite old screenshots as current UI truth without rechecking the app.
