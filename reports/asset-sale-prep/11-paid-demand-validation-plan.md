# Paid Demand Validation Plan

Status: Draft
Owner: Founder
Created: 2026-05-31

## Goal

Use paid acquisition to create buyer-quality demand evidence, not vanity waitlist numbers.

## Core Hypothesis

Free local AI is the hook. Cloud waitlist is the upgrade path.

Positioning:

> Start with a free private AI that runs locally. Join the cloud waitlist only when you need bigger models or heavy tasks.

## Why This Helps A Sale

Weak signal:

> We bought 10,000 waitlist signups.

Strong signal:

> We spent $2,400, drove 1,120 landing visits, collected 410 qualified waitlist signups, got 96 TestFlight requests, 38 direct replies, and 12 people saying they would pay $20/month for cloud or pro features.

## Campaign Structure

Run three pages and three ad groups.

### Page 1: Free Local AI

Audience:

- People who want a private AI assistant.
- Students, knowledge workers, privacy-conscious consumers.

Promise:

- No login required for local mode.
- Works offline where supported.
- Private by default.
- Cloud waitlist only for heavy tasks.

Primary CTA:

- Join local beta / TestFlight.

Secondary CTA:

- Join cloud waitlist.

### Page 2: Developer / Local LLM

Audience:

- Local LLM users.
- Developers using Claude Code, Codex, Cursor, VS Code, terminal agents.

Promise:

- Local/BYOK/multi-provider AI suite.
- Desktop, CLI, Chrome, and VS Code direction.
- Explicit trust boundaries.

Primary CTA:

- Join developer preview.

Secondary CTA:

- Request technical demo.

### Page 3: Sensitive Work

Audience:

- Professionals with private notes, company docs, legal/research material, personal journaling.

Promise:

- AI for private notes and sensitive thinking.
- Keep local by default.
- Cloud only by explicit consent.

Primary CTA:

- Join private beta.

Secondary CTA:

- Book founder call.

## ChatGPT Ads Test

Use ChatGPT Ads as a targeted validation channel if available to the account.

Recommended first test:

- $500 CPC campaign.
- $500 CPM campaign.
- Same landing pages.
- Same tracking.
- 7-day run.

Decision rule:

- Prefer CPC until CTR and qualified signup rate are proven.
- CPM is only attractive if CTR is strong enough to lower effective CPC.

Copy guardrails:

- Do not claim to beat ChatGPT, Claude, or OpenAI.
- Do not imply affiliation with OpenAI or Anthropic.
- Avoid regulated/sensitive claims such as legal/medical/financial advice.
- Avoid fear-based privacy claims.
- Use "local," "private by default," "works offline where supported," and "cloud waitlist for heavier tasks."

## Metrics To Track

| Metric | Target |
| --- | --- |
| Landing page conversion to waitlist | 10-25%+ |
| Cost per qualified signup | Under $5 consumer/dev, under $25 prosumer |
| Survey completion rate | 40%+ |
| Reply to follow-up | 10%+ |
| TestFlight request rate | 15-30%+ |
| Booked call / deposit / LOI | Strongest signal |

## Signup Form Questions

Ask:

1. What would you use AGI for?
2. What do you use today: ChatGPT, Claude, Gemini, Perplexity, local LLM, Cursor, other?
3. Which mode interests you most: free local, BYOK, cloud waitlist, developer tools?
4. Would you pay: $0, $5/month, $10/month, $20/month, team plan?
5. Do you want TestFlight / desktop preview / founder call?

## Buyer-Ready Output

After 14 days, create:

- Ad spend summary.
- Campaign-by-campaign CAC.
- Qualified signup count.
- Persona breakdown.
- TestFlight requests.
- Survey quotes.
- Follow-up reply examples.
- Redacted signup export.
- Interpretation: what the market wanted and what it ignored.

## Kill Rules

Stop or revise if:

- Cost per qualified signup exceeds $25 with no high-intent responses.
- Signups do not complete the survey.
- No one replies to follow-up.
- Users only want free cloud compute.
- Ads attract unqualified geographies/personas that buyer would discount.

## Recommended Timing

Do not run the paid sprint before the demo path is credible.

Recommended order:

1. Fix mobile P0 test failures.
2. Prepare landing pages and tracking.
3. Record demo clips.
4. Run 7-14 day paid validation.
5. Add results to buyer deck and data room.
