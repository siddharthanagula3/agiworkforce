How to use: each row is one user-facing feature, option, permission, entitlement, data flow or purchase path in `apps/mobile` (iOS and Android), with the store rule it must meet, whether ChatGPT or Claude ships the same thing, and a verdict.
Fix a FIX row before submission, keep a GATE row out of the store build, and settle the OWNER DECISION rows first.
Code paths are relative to `apps/mobile/` unless they start with `apps/`, `packages/` or `docs/`. The tree read was `main` at 3547a5254b, with other lanes' uncommitted edits present.
