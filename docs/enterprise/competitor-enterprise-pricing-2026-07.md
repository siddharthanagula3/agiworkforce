## 2. What each tier includes (feature gates)

**Anthropic Team → Enterprise**: Team adds SSO + domain capture, JIT provisioning, role-based permissions, spend controls, enterprise search connectors (Slack/M365/Drive/GitHub). Enterprise adds SCIM, audit logs, custom data retention, Compliance/Analytics APIs, customer-managed encryption keys, US-only inference option, and HIPAA-readiness/BAA — but the BAA specifically requires the **sales-assisted** (50-seat-minimum) path, not self-serve. Usage (chat, Claude Code, Cowork tokens) is billed separately at API rates on top of the seat fee at every tier — the seat fee is access-only, not a usage allowance.
Source: [claude.com/pricing](https://claude.com/pricing), [Claude Help Center — Team plan](https://support.claude.com/en/articles/9266767-what-is-the-team-plan), [Claude Help Center — Enterprise plan](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan)

**OpenAI Business → Enterprise**: Business (self-serve) includes GPTs, Projects, Apps, Company Knowledge, ChatGPT Agent, Deep Research, and Codex, with a minimum of 2 seats. Enterprise is the only tier that is explicitly "contact sales" with no public list price; secondary sources describe SCIM, EKM (customer-managed encryption keys), data residency, RBAC, domain verification, audit logs, 24/7 SLA support, and custom legal terms as the Enterprise gate. Non-profits get a 20% discount off Business ($16 annual / $20 monthly).
Source: [OpenAI — Introducing ChatGPT Team](https://openai.com/index/introducing-chatgpt-team/), [OpenAI Help Center — What is ChatGPT Business](https://help.openai.com/en/articles/8792828-what-is-chatgpt-team) (official pages returned 403 to automated fetch during this research; numbers corroborated via search-result snippets citing these URLs directly, so treat the Business self-serve numbers as verified-by-citation but re-confirm on openai.com/business/chatgpt-pricing before quoting externally). Enterprise $/seat figures are **UNVERIFIED** — OpenAI has never published an Enterprise list price.

**Cursor Business → Enterprise**: Business/Teams gives Pro-equivalent AI access plus centralized billing/admin, team rules, cloud agents with shared context, usage analytics, privacy mode, and SAML/OIDC SSO — notably, SSO is already in the $40 self-serve tier, not gated to Enterprise. Enterprise (custom, contact sales) adds pooled usage, invoice/PO billing, SCIM, granular access controls, auto-run/browser/network controls, audit logs, service accounts, and an AI code-tracking API.
Source: [cursor.com/pricing](https://cursor.com/pricing)

**GitHub Copilot Business → Enterprise**: Business ($19/seat/mo) covers the IDE/CLI/GitHub Mobile coding environment, a broad model catalog, a monthly AI-credit pool (documented as 1,900 credits/user in secondary sources, not confirmed on the official docs page fetched), and org-level Copilot policy controls. Enterprise ($39/seat/mo) adds GitHub.com chat integration, priority access to new models, a larger credit pool (secondary sources cite 3,900/user), and requires GitHub Enterprise Cloud. This is the only vendor researched with a **fully public, flat Enterprise list price** — no "contact sales" gate.
Source: [docs.github.com/copilot/get-started/plans](https://docs.github.com/en/copilot/get-started/plans), [github.com/features/copilot/plans](https://github.com/features/copilot/plans) (blocked 403 on direct fetch, corroborated via docs.github.com and search snippets)

## 3. The differentiated angle: offline/air-gapped is a gap in every competitor above

None of Anthropic, OpenAI, Cursor, or GitHub Copilot ship a **fully offline, provably zero-egress** enterprise tier — every plan above is cloud-hosted SaaS. Anthropic's closest analog is "US-only inference," which restricts data _residency_ but does not remove cloud dependency. This matches the existing GTM thesis (`project-gtm-business-model` memory): compete on "your models, no markup, private, everywhere," not on frontier-model quality. For regulated/air-gapped buyers (finance, defense, healthcare with strict BAA/on-prem requirements), there is currently no cloud-vendor SKU to buy — that's the pricing-power lever for AGI Workforce Enterprise-Local, consistent with `docs/enterprise/enterprise-local-design.md` §4 FD-3's recommendation to ship the air-gapped identity tier first.

## 4. Recommendation for AGI Workforce Enterprise-Local

Grounded in the researched anchors above and the existing edition split already proposed in `docs/enterprise/enterprise-local-pricing-decisions.md` (FD-1: Team self-serve + Enterprise sales-assisted, features `org-policy`/`audit-export`/`self-hosted-gateway`/`air-gapped`/`sso-scim`):

### AGI Workforce Team (self-serve, per-seat/month)

- **$35/seat/mo billed annually, $45/seat/mo billed monthly.** Minimum 5 seats.
- Positioning: above Anthropic's $20 and OpenAI's $20 Business baseline, below Cursor's $40 flat rate — justified because this tier already includes org-policy + audit-export (governance features Anthropic/OpenAI gate to Enterprise, and Cursor doesn't offer at all at Business).
- Includes: Local-mode BYOK with no markup (the existing free-tier promise, now with org controls layered on), `org-policy`, `audit-export`, offline license activation, connected (Clerk) SSO identity.
- Rationale for pricing above the cloud-only anchors: seats here are consuming the buyer's own model spend (BYOK, no markup) rather than AGI Workforce's inference margin — the seat fee is monetizing governance/audit/admin tooling on top of a product that is _already_ cheaper to run than metered-usage competitors, which supports a premium on the seat line itself.

### AGI Workforce Enterprise (sales-assisted, custom/volume)

- **Published anchor price: $75/seat/mo annual (list), volume-discounted 20–30% at 100+ seats** — publish this list price rather than going full "contact sales," following GitHub Copilot Enterprise's model (the only vendor researched with a transparent Enterprise number) rather than Anthropic/OpenAI/Cursor's opaque custom-quote approach. A published anchor is a credible differentiator in security-buyer conversations where "contact sales" reads as evasive.
- Minimum 20 seats (matches Anthropic's self-serve Enterprise floor; well below OpenAI's ~150-seat UNVERIFIED floor, intentionally undercutting that friction point for mid-market regulated buyers who are the actual air-gapped-demand segment).
- Includes everything in Team plus `self-hosted-gateway`, `air-gapped` tier (license file + local OS identity, no phone-home — per FD-3/FD-4 in the design doc), SCIM, priority support.
- This is the tier that should carry the pricing power: it is the only SKU among all five vendors compared that can credibly claim zero cloud dependency, so pricing it near GitHub Enterprise ($39) or even above Cursor Enterprise's estimated ~$290–385/seat/yr (~$24–32/mo effective) is defensible — recommend landing meaningfully above the SaaS competitors' _effective_ per-seat cost, since the buyer is paying for a capability (air-gapped operation) literally unavailable elsewhere at any price today.
