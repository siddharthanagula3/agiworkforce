# Wire-or-Cut Decisions

Status: Active

Owners: Product integration and the owning surface

This ledger records decisions for code that implements or calls a product
capability but has no production entry point. The default is to cut dead code.
Each exception must identify a real runtime selection mechanism or a bounded
follow-up ticket.

## 2026-07-29 — Desktop IPC Baseline

| Capability                                            | Decision | Evidence and retained path                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Desktop planning preview                              | Cut      | `apps/desktop/src/api/planning.ts`, both planning preview components, and `planningStore.ts` were unmounted and invoked nonexistent `agent_preview_*` commands. The live research-plan experience remains in the web chat.                                                                                               |
| Desktop LLM council                                   | Cut      | `apps/desktop/src/api/council.ts` and `councilStore.ts` were referenced only by archived UI and invoked nonexistent `llm_council_query` / `llm_council_get_status` commands.                                                                                                                                             |
| Desktop image gallery/style presets                   | Cut      | The gallery, preset picker, and gallery store had no production import path; their generation call targeted a command that is not part of the native IPC contract. Supported image generation remains on reachable product paths.                                                                                        |
| Desktop slash `execute-plan` handler                  | Cut      | The handler was reachable only from the abandoned planning store and had no mounted chat entry point. Shared slash-command reconciliation is tracked separately in Ticket 1D.                                                                                                                                            |
| Shared subscription wrappers                          | Cut      | Five `desktop-command-client` subscription functions had no consumers and no matching registered native commands. Canonical checkout, plan management, and cancellation remain server-authoritative in the web billing boundary.                                                                                         |
| Shared email credential-migration wrappers            | Cut      | The two wrappers had no consumers and no matching registered native commands. The live database/keychain credential path is unchanged.                                                                                                                                                                                   |
| Shared voice cancellation/interrupt wrappers          | Cut      | The two wrappers had no consumers and no matching registered native commands. Existing registered voice playback and cancellation commands remain available through their real callers.                                                                                                                                  |
| Renderer-exposed Stripe command set                   | Cut      | Nineteen Tauri command functions had no frontend callers, `billing_initialize` had no startup caller, and both feature branches exposed a phantom API. Local renderer Stripe ownership was removed; web/API billing remains canonical, while the internal `BillingState` used by agent entitlement checks is retained.   |
| Native cloud CRUD and transfer commands               | Cut      | Six `cloud_*` commands were registered fail-closed placeholders that could only return `ERR_CLOUD_NOT_IMPLEMENTED`. The two transfer commands called those placeholders and their TS wrappers had no consumers. Managed Cloud persistence remains on the live shared Web API client boundary in `services/cloudChat.ts`. |
| Legacy native AI project/code commands                | Cut      | Eight uncalled `ai_*` commands duplicated the mounted agent, workspace, and guarded tool paths while keeping project context only in memory. Their two otherwise-unused managed states and web-development mocks were removed with the native module.                                                                    |
| Legacy custom updater command layer                   | Cut      | Five uncalled commands and their unused TS contract duplicated the mounted updater experience. Desktop updates continue through the signed Tauri updater plugin, and version reads continue through `@tauri-apps/api/app`.                                                                                               |
| Orphan native debug/background/GitHub/doctor wrappers | Cut      | Twenty-two uncalled commands owned isolated managed state or renderer mocks but no product entry point. Mounted background agents and Git workflows remain; shared diagnostic checks remain available as Rust internals, while startup recovery retains its separate sanitized diagnostic export.                        |
| Runtime-selected local model list commands            | Keep     | `llm_list_llamacpp_models`, `llm_list_lmstudio_models`, and `llm_list_vllm_models` are selected by provider name at runtime and are explicitly documented in `apps/desktop/wiring-allowlist.json`.                                                                                                                       |
| Remaining temporary Desktop IPC exceptions            | Cut      | The final 52 registrations had no production command-name occurrence. Their native functions remain internal where Rust callers still use them, but they are no longer exported through Tauri; obsolete renderer mocks were removed. No temporary Ticket 1C exception remains.                                           |

The enforcement policy and reviewed exception format are defined in
`docs/decisions/2026-07-29-desktop-ipc-orphan-baseline.md`.

## 2026-07-30 — Enterprise and Gateway Database Boundaries

| Capability                                                | Decision | Evidence and retained path                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Enterprise configuration and support schema               | Wire     | Migration `0076_enterprise_control_plane_tables.sql` owns SSO/directory configuration, organization policy, audit, usage-ledger, and support-case relations with RLS. Existing Web/admin and gateway routes retain their bounded configuration/support responsibilities.                                                                                                                                                                                                                   |
| First-party SSO sign-in and SCIM provisioning runtime     | Defer    | Configuration storage is real, but authentication/provisioning enforcement is a Phase 3 enterprise product decision. The Admin readiness UI states this boundary explicitly and does not claim that configuration alone enables SSO or SCIM. The unconsumed directory-sync webhook that returned HTTP 501 after signature verification was removed, along with its unused secret contract; no externally addressable provisioning endpoint is advertised until the runtime is implemented. |
| Gateway chat, pairing, and mobile approval relations      | Wire     | Migration `0077_gateway_compatibility_tables.sql` owns the five pre-existing gateway relation names. Reachable routes now use `getUserScopedClient`; the former privileged compatibility allowlist was deleted.                                                                                                                                                                                                                                                                            |
| One-off schema application scripts and Docker init mounts | Cut      | `pnpm db:migrate` is the sole schema authority. It records exact checksums in `schema_migrations`; CI proves clean apply, no-op reapply, drift-free verify, route/relation ownership, and a two-tenant RLS probe.                                                                                                                                                                                                                                                                          |
