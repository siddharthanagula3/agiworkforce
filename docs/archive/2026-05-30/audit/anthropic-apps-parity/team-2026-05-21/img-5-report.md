## TL;DR — one bullet per surface

- **Web auth (`claude.ai/login`):** split-screen sign-in with live product-preview right pane, narrow auth ladder (Google + email), explicit Apple-desktop CTA, logged-out plan-card grid in nav. Most likely v1-gap = product-preview pane; cross-check `apps/web/app/signup`.
- **Web public (`claude.com/pricing` + `support.claude.com`):** three-audience tab toggle (Individual/Team/API) at one URL, per-plan support articles with Intercom chat bubble + right-rail TOC + last-updated stamps, and explicit overage doc with mobile-IAP caveat — likely the biggest v1 gap given AGI may not have a public `/pricing` or support subdomain yet.
- **Chrome extension:** Chrome side-panel API (not popup) with paid-plan gating banner, first-class **Ask vs Act** permission pill on composer, **Quick mode** (Haiku default, Opus-fast at surcharge), `/`-prefix shortcuts with schedule toggle, desktop pairing handshake, sensitive-site denylist, in-stream permission asks with ⏎/Esc/⌘⏎ keyboard ladder.
- **VS Code extension (`anthropic.claude-code`):** sidebar + full-editor-tab modes, persistent file-context chip in composer, **Modes** popover (Ask / Edit auto / Plan / Bypass with ⇧+Tab cycle) + independent **Effort** slider + Thinking toggle + Toggle-fast-mode (Opus-only), Local/Web session split with search, granular VS Code-native settings (13 toggles including `claude-code.allowDangerouslySkipPermissions`).
- **Cursor + Claude Code:** same extension hosted in Cursor, with OS-level permission-state sharing across Terminal/Cursor/VS Code, runtime-generated `/team-onboarding` walkthrough, inline diff preview with apply/reject chips, and host-delegated settings (forwards to Cursor's own settings IA when present).
