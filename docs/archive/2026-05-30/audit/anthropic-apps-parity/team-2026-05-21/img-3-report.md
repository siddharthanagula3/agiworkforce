## Summary observations

- **Navigation paradigm:** drawer-only, no bottom tab bar; five top-level destinations (Chats / Projects / Artifacts / Code / Dispatch).
- **Settings is a flat sheet** (not a nested screen) with rich state previews inline ("Max plan", "Dark", "EN"). Card-style top corners + X close confirms it's a modal presentation.
- **Three distinctive Claude-mobile primitives** worth flagging as P0 cross-validation candidates: (1) reasoning chip + thought-process bottom sheet, (2) Add-to-Chat sheet bundling attachments + tools + style + project, (3) full Cowork/Code remote-session pairing UI.
- **iOS-platform fidelity:** native action sheets, rounded card-sheet Settings, native iOS share/StoreKit handoff, granular Permissions screens, Haptics toggle, HealthKit beta integration. Claude is leaning hard on iOS-native components rather than custom web views.
- **Mobile model picker** keeps "Extended thinking" as an _orthogonal_ toggle (model × thinking flag = product of two dimensions), inside one popover.
