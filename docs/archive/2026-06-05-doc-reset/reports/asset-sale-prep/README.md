# Asset Sale Prep

Status: Current
Owner: Founder
Created: 2026-05-31
Purpose: buyer-facing and diligence-ready paperwork for a potential strategic asset sale or acquisition discussion.
Retention: Keep while sale outreach is active; archive after a completed transaction or strategic reset.

## Important Notice

This package is business preparation material, not legal advice. Have an M&A/IP attorney review any NDA, LOI, asset purchase agreement, assignment, disclosure schedule, or buyer communication before signing or sending confidential materials.

## Process Rule

Do not send source code, private repo access, app-store credentials, API keys, customer/user data, or internal reference archives before NDA, buyer qualification, and attorney review. First contact should use only the teaser and short demo videos.
