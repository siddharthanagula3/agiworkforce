## Cross-lane patterns

1. **Orphan trees are invisible to existing tools.** `cargo build` doesn't fail on uncompiled code; `pnpm typecheck` doesn't fail on un-imported TS files. Both V1 and V6 surfaced this. The cli has ~118 orphan files; we don't know what the per-surface orphan-rate is elsewhere. **Recommended:** add a CI module-graph reachability check that asserts every `.rs` file under `apps/*/src/` has a `mod`/`pub mod` declaration reachable from `lib.rs` / `main.rs`, and every `.ts`/`.tsx` file under `apps/*/src/` is reachable from the production entry point.

2. **Two parallel OpenAI codebases.** `apps/web/lib/llm-providers/openai.ts` (fetch-based, used by `/api/llm/v1/chat/completions`) vs `packages/providers/openai/src/index.ts` (SDK-based, used by CLI/desktop via `@agiworkforce/llm-normalize`). Known from R22 audit but still unconsolidated. The web variant handles both cached-token shapes correctly; the packages variant was not audited in this round (out of V3 scope).

3. **Production-silent helpers.** V3's `toOtelAttributes` finding is the canonical pattern: a helper has full unit tests AND a tight contract, but no production code calls it. The unit tests give false confidence. **Recommended:** introduce a "call-graph reachability" assertion in CI that flags exported helpers with test coverage but zero non-test callers.

4. **Commit-classifier drift.** V6 found `d7e8e4191` shipping 2,360 LOC of mobile feature code under a `docs(visual-verification):` subject. Breaks `git bisect`, `git blame`, and changelog-from-commits. **Recommended:** pre-commit hook that warns when the commit subject prefix (`feat/fix/docs/test/refactor`) doesn't match the dominant file-class in the diff.

5. **Migration paths for behavior gates.** V5 found that users with pre-v1 `chat_storage_mode = "cloud"` in their settings would have had sync silently re-enabling itself after the gate. Now fixed via load-time coercion. Pattern to apply elsewhere: any time you flip a default OFF, also handle the persisted-as-ON case at load time.
