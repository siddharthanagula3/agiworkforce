# Feature comparison: ChatGPT, Claude, Perplexity, Gemini and our app (observed 2026-11-12)

Status: Historical snapshot
Owner: Product (founder)
Last updated: 2026-11-13

Every feature and option that the four competitor iPhone apps show in the founder's 229 screenshots, one row each, with what each app calls it, the pictures that prove it, whether our mobile app has it, and the next step. This is dated inventory, not authority: it records what the pictures show and what the code in this worktree did on 2026-11-13. The open work that follows from it is tracked in `audit/live-check/mobile-feature-gaps-2026-11-13.md`, not here.

## How to read the table

- One row is one feature or option. The name in backticks is its key; `features.jsonl` holds the same row as data, with every label, option, picture and code line.
- An app's cell shows the label on screen in quotes, its choices in round brackets and the picture numbers in square brackets (`[1184]` is the file `IMG_1184_<picture name>.PNG`; `screen-map.md` names every picture). `shown` means a control with no text label; `implied` means the pictures show the result but not the control.
- `not in the pictures` means only that. The pictures are one account on one day, so an app may well have a feature that no picture shows. It never means the app lacks it.
- **Ours** is the code in this worktree, uncommitted changes included: `Yes`, `Partly`, `No`, `No, by decision` (a decision record or a release switch turns it off) or `Does not apply` (the competitor's own content). `in Cloud only` marks a feature that needs Cloud mode; the four competitor apps are cloud apps, so this counts as having it.
- **Next** follows one rule. `Build` or `Finish`: three or four of the apps have it, or both ChatGPT and Claude do. `Your call` or `Finish if wanted`: one of ChatGPT and Claude has it. `Skip unless wanted`: only Perplexity or Gemini has it. `None`: we have it, or a decision stands.
- A `<price>`, `<user name>` or similar placeholder stands for content that is personal or that should not be kept as a fact here.

## Method and limits

- **Listing.** Each app's layout files in this folder were read section by section and every capability, setting and option was written down with the pictures that show it: 877 items. Items that are the same feature in different apps were grouped: 512 features.
- **Our app.** Each feature was looked up in the code of `apps/mobile` with a file and line as proof. All 512 were checked once. The 125 features that two or more apps share were checked a second time, independently and more deeply; the two checks disagreed on 20, most of them over how to count a Cloud-only feature. Each disagreement was settled by hand against the code; in all, 38 rows carry a hand ruling, and the top gaps were confirmed against the pictures.
- **Checked once only.** The 387 features that a single app has rest on one reading of the code. Treat a `No` or `Partly` there as likely, and confirm it before building.
- **Read, not run.** Our side is what the code does when read, not a run of the app; the local server was off. Behaviour that only a running app shows (a notification actually arriving, a server switch being on) is marked in the row where it matters.
- **Not covered.** Layout, size and style are in `comparison.md`. Anything the competitor apps do that the pictures do not show is absent from this table.
- **Records that disagree with proof.** The app language picker was removed from the app (commit 76396a64d6), but register row GAP-034 still describes it as present, and the 2026-09-27 decision record says ChatGPT has no such row while picture IMG_1215 shows one.
