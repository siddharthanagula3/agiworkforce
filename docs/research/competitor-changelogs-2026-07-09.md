## 4. Parity-relevant deltas (mapped to matrix rows)

1. **VS Code Extension / Chrome Extension rows citing "Codex app features"** — the competitive target itself just collapsed: Codex is no longer a separate app, it's a mode inside one ChatGPT desktop app alongside Chat and Work. If AGI Desktop's parity target was "match Codex-as-standalone-app," that target moved; matrix should note the new competitive shape is "one desktop app, three modes" (Chat/Work/Codex), which is closer to AGI's own single-app, single-window philosophy ([[feedback-desktop-single-tab-architecture]]).
2. **New competitor product with no matrix row: ChatGPT Work.** A distinct "Work" agent mode (deliverable-producing: docs/sheets/slides/sites, long-horizon, multi-app context gathering) exists in ChatGPT now, on web/mobile/desktop for eligible paid plans. This is not represented anywhere in the current matrix and is a gap the matrix should track as a new competitive target, likely closest to Claude Cowork on the Anthropic side (see #3).
3. **Claude Cowork expanding to web + mobile (2026-07-07)** is the same trend from the opposite vendor: Anthropic's async/background agentic-task product is no longer desktop-only. Matrix rows for Mobile and Web surfaces should account for "start on one device, continue in background, review from phone" as the now-standard shape for both Claude and ChatGPT's non-coding agent products.
4. **Claude in Chrome reached GA on 2026-07-01** (was research preview/beta) — the matrix's Chrome Extension section target should be updated from "Claude in Chrome (preview)" framing to GA behavior: multi-tab group control, native app navigation (Slack/Calendar/Gmail/Docs/GitHub) without step-by-step prompting, saved-prompt shortcuts. AGI's Chrome extension parity bar just got measurably higher.
5. **ChatGPT Atlas sunset** — if any AGI competitive research assumed "match Atlas browser" as a target, that target is being retired by OpenAI itself (~30 days from 2026-07-09 per press, unconfirmed on an OpenAI-owned page). Don't build new parity work against Atlas-specific browser UI; the successor is ChatGPT desktop app browsing + a Chrome extension, which folds into the existing Chrome Extension and Desktop rows.
6. **GPT-5.6 (Sol/Terra/Luna) is now GA** replacing the size-based (mini/nano) naming scheme with durable capability tiers. `packages/types/src/models.json` and any BYOK/model-picker code referencing GPT-5.5 tiers should be checked against this — per CLAUDE.md's own rule, model IDs must come from the repo's models.json and be verified, not assumed; this changelog does not by itself update that file.
7. **Canvas reportedly removed from GPT-5.5 Instant/Thinking**, replaced by inline writing/code blocks in chat (UNVERIFIED — direct fetch blocked, sourced from a WebSearch-tool cached summary of help.openai.com). If AGI's parity matrix has a Canvas-equivalent target modeled on ChatGPT's dedicated Canvas UI, re-verify this before committing UI work to a screen that may be getting deprecated upstream.
8. **Claude Trusted Devices (2026-06-25)** — secure remote control of Claude Code sessions from a trusted device — has no obvious matrix counterpart; if AGI CLI/Desktop plans any "control this session from another device" feature, this is the reference implementation to check.
9. **Claude Tag (Slack @-mentions, 2026-06-23) and OpenAI's ChatGPT-in-Slack-adjacent workspace agent pricing (2026-07-06 token billing)** both push chat-platform integration further; matrix's Billing/Usage section doesn't currently model per-integration credit consumption the way OpenAI's new Workspace Agent token pricing does — worth a note if AGI ever bills Slack-triggered agent runs.
10. **Anthropic's "reflect on how you use Claude" (2026-07-09) monthly-recap/usage-pattern feature** has no ChatGPT equivalent found in this pass and no AGI matrix row; flag as a possible new personalization/analytics parity target rather than something to ignore as noise.
