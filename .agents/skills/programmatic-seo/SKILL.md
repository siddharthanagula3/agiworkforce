# Programmatic SEO

Use this skill for planning scaled page systems that can rank without becoming thin duplicate content.

## Workflow

1. Identify the page pattern: persona, comparison, integration, glossary, location, alternative, or template variant.
2. Define the unique value each generated page must contain.
3. Design the URL pattern, hub page, internal-linking model, and sitemap/indexation plan.
4. Specify required source data, screenshots, examples, customer proof, or proprietary insights.
5. Add quality checks that catch duplicate, empty, or near-template-only pages before publishing.

## Boundaries

- Technical crawl errors, 404s, canonical tags, and traffic drops belong to a technical SEO audit flow.
- Do not recommend bulk publishing until uniqueness and indexation checks are defined.
