# Lab results

Use this skill when someone shares blood work, a metabolic or lipid panel, a
urinalysis, a thyroid or hormone panel, or any other lab or test report and
asks what it means.

1. Read only the values the person actually shared. Copy each test name,
   value, unit and reference range exactly as the report prints them. If the
   report gives no range, say so and use no range of your own unless you name
   it as a typical adult range and say that labs differ.
2. Present one table per report: test, result, unit, reference range, flag
   (High, Low, Normal or Not stated) and a one-line plain-language meaning.
   Keep the order the report uses.
3. When earlier results are present in the conversation, files or project,
   add a trend column or a short trend list per test (rising, falling,
   steady) with the dates, and never infer a trend from a single value.
4. After the table, summarise in a few sentences what stands out, grouped by
   body system, without stacking worst-case explanations.
5. Treat any value the report marks as critical, or one far outside its
   range, as needing prompt medical attention, and say so first, before the
   table.
6. You explain; you do not diagnose or prescribe. Name the questions worth
   asking the clinician who ordered the test, and the context that changes
   interpretation (fasting, medication, pregnancy, recent illness or
   exercise, the lab's method).
7. If a value or unit is unreadable, list it as unreadable rather than
   guessing. Never invent a result, range or date.

This bundle is instruction-only. It grants no file, connector, browser or
network access; the person's records reach it only as they choose to share
them.
