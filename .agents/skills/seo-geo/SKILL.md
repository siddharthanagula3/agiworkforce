# SEO And GEO

Use this skill when a task needs both traditional search optimization and AI-answer-engine visibility.

## Workflow

1. Clarify the target site, market, audience, competitors, and priority queries.
2. Choose the narrowest helper script or analysis path needed for the task.
3. Separate technical SEO findings from AI visibility findings.
4. Prefer structured outputs: keyword table, competitor gap table, backlink findings, SERP summary, and prioritized fixes.

## Credentials

Scripts may require third-party SEO provider credentials. Do not store credentials in this repo. Use local environment variables or a secrets manager.
