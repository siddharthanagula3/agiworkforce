# Frontend design review

Use this skill to assess a user-facing interface or frontend change.

1. Identify the primary user task and the visible hierarchy that should support it.
2. Inspect the rendered interface when available, including common desktop and narrow viewport sizes.
3. Check readability, spacing, contrast, focus order, labels, keyboard access, and reduced-motion behavior.
4. Exercise primary and secondary controls and inspect loading, empty, error, disabled, and success states.
5. Look for clipping, overflow, layout shifts, stale labels, dead controls, and unexpected navigation.
6. Report concrete issues with location, user impact, and a focused recommendation.

Do not infer visual quality from source code alone when a rendered surface is available.
