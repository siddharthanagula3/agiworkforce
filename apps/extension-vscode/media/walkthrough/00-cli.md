# The AGI CLI runs your sessions

Chat, `@agi` and developer sessions start the AGI CLI in this environment, on this computer or on the remote host you are connected to.

- **Install AGI CLI** runs `curl -fsSL https://agiworkforce.com/install.sh | bash` in a terminal. The installer verifies the release signature and checksum before it installs anything.
- On Windows, run the same command in Git Bash or WSL.
- Already have the CLI somewhere else? Set `agiWorkforce.cliPath` to it.
