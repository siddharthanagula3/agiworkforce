# Memory follows your account

- **What it keeps:** short facts about you and your work, saved to your AGI Cloud account and shared with the web app, the CLI and mobile.
- **When it is used:** facts are sent with your turns only while memory is on. Turn it off at any time and nothing saved is sent.
- **What you control:** add, edit or delete any fact, list terms memory must never keep, or forget everything at once from the Memory menu.
