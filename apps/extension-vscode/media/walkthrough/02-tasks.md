# Foreground here, background in the cloud

Developer sessions started in the editor run on your machine while the editor is open.

**Show Cloud Tasks** lists AGI Work runs started on any device, with their state, age and pending approvals. Approve or reject a run from the list, pull its changes into the workspace, or open it on the Web.

**Continue in the Cloud** is an explicit handoff: you review the repository and branch first, and a cloud session clones them from GitHub. The extension does not pretend a local prompt is running in the cloud.
