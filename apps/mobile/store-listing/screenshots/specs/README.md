# Screenshots Specification — AGI Mobile Draft

Status: Current draft, not submission-locked
Last updated: 2026-06-05

Screenshots must be real captures from the submitted binary. Current screenshot story follows Local Mode first with Cloud Managed invite gates.

## Locked Draft Sequence

1. **Local chat**: local model chat in progress, no account required.
2. **Model picker**: local models selectable, Cloud Managed rows locked.
3. **Drawer**: AGI header, search, Projects, Artifacts, AGI Agent with Cloud tag, Recents, Settings.
4. **Settings**: Local settings rows active and Cloud rows invite-gated.
5. **Tool use**: compact tool status row with command preview and expandable details.
6. **Cloud invite**: AGI Agent or subscription row opens invite/waitlist modal.

## Capture Rules

- Do not use generated mockups for store submission.
- Do not show unavailable public cloud features as live.
- Do not show direct provider-key entry on Mobile.
- Do not show placeholder text, fake accounts, fake paid subscriptions, or fake production status.
- Re-run captures after any UI change to drawer, settings, model picker, onboarding, chat composer, or cloud invite modal.
