## Full Description Draft

```
AGI is a mobile AI workspace for people who use AI every day.

Start in Local Mode for private on-device and local-model chat. Use projects, recents, search, files, voice, memory controls, and polished settings from one app.

Cloud Managed features such as AGI Agent, connectors, plugins, skills, subscriptions, and cross-device cloud chat are visible but invite-gated while the cloud beta is prepared.

KEY FEATURES

• Local Mode chat for demo-ready private workflows
• Model picker with local models and locked Cloud Managed options
• Projects, recents, search, profile, and new chat from the drawer
• Settings for personalization, memory, appearance, accent color, notifications, voice, safety, data controls, and parental controls
• Cloud invite flow for AGI Agent, connectors, plugins, skills, subscription, and account features
• Tool-use UI with status, command preview, and expandable details

PRIVACY

Local chats stay local unless the user explicitly enters a Cloud Managed path. Cloud features require invite or waitlist access and must remain visually separate from Local Mode.

SUPPORT

Docs and changelog: https://agiworkforce.com
Email: support@agiworkforce.com
Status: https://status.agiworkforce.com
```
