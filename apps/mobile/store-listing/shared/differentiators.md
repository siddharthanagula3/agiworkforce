# Mobile Differentiators — Current Draft

Status: Current draft
Last updated: 2026-06-05

These differentiators must match the current Mobile implementation.

## 1. Local Mode First

AGI Mobile starts with a private local workflow: chat, model selection, projects, recents, search, memory controls, voice, data controls, and tool-use status in one app.

Public-facing claim:

> Start locally with a private AI workspace on your phone.

## 2. Cloud Managed Invite Path

Cloud features stay visible but gated: AGI Agent, connectors, plugins, skills, account, subscription, restore purchases, and cloud chat open the invite/waitlist flow until cloud access is enabled.

Public-facing claim:

> Cloud Managed features unlock through invite access.

## 3. Cross-Surface Workspace Direction

Mobile should align with AGI Web and Desktop: projects, artifacts, tools, memory, model choice, and cloud chat should feel like one product while preserving Local and Cloud trust boundaries.

Public-facing claim:

> One AGI workspace across phone, desktop, and web.
