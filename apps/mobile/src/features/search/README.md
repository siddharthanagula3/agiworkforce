# Mobile search

Status: Current
Owner role: Mobile lead
Last updated: 2026-07-30
Purpose: Mode-aware, on-device projection of searchable Mobile chats, projects, Library images, and artifacts.

## Rules

- Search only data already authorized and hydrated for the active Local or Managed Cloud mode.
- Keep Local chat and project data on device; remote conversation search stays behind the existing Cloud-mode search boundary.
- Return typed result groups so navigation surfaces can label the source and route to the exact item.
- Do not persist a second copy of Library or artifact content.
