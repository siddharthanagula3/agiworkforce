## Company page post

**Headline:** AGI Mobile is live — free Local Mode with Cloud by invite

We are preparing AGI Mobile for launch.

It is an AI assistant with Local and Cloud-invite modes. Local mode works in airplane mode. Cloud unlocks hosted sync and managed compute by invite.

**What is on-device AI, and why does it matter?**

Modern phones increasingly support local AI runtimes. AGI Mobile starts with clear Local Mode, then lets users request AGI Cloud when they need hosted models, sync, or managed tools.

The implication: a free Local AI assistant for supported devices, with no silent switch from Local work to Cloud.

**v1 feature set:**

- Local chat with visible model state
- Voice input where local device speech support is available
- Memory, personalization, projects, and artifacts preview
- App lock, age gate, data controls, and privacy copy
- Cloud invite and waitlist flow for hosted workflows
- DPDP Act 2023 and EU AI Act disclosure readiness remain launch-review items

**Local-first acquisition.** Local Mode is the free entry point. Cloud should feel like an upgrade, not a repair.

**Transparent roadmap.** Cloud models, sync, and team features are invite-gated. The Local experience is the free acquisition path.

## Founder / personal post variant

We are preparing AGI Mobile. Here is what it is and why it exists.

**What it is:** a free AI assistant for iOS and Android with Local and Cloud-invite modes. Local mode works offline. Cloud opens with invite access.

**Why we built it this way:** on-device AI support varies heavily by phone, OS, runtime, RAM, model size, and battery constraints.

That is why the product has to show Local, unavailable, downloadable, and Cloud-invite states clearly instead of pretending every device can run every model.

**What it takes:** the hardest problem is not writing a chat screen. It is making local model state, download state, privacy copy, and Cloud gating feel understandable on a phone.

**What is next:** cloud features on a waitlist. We will not launch them until the local experience is polished enough that cloud feels like an upgrade, not a repair.
