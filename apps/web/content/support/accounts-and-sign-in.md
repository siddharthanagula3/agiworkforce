## Signing in

Open [Sign in](https://agiworkforce.com/login) and use the email address or sign-in
provider associated with your account. Follow the password or email-code option
shown on screen.

If a verification code has not arrived, check your spam folder and confirm the
email address, then use **Resend code** when it becomes available. If you forgot
your account password, choose **Forgot password?** on the password screen.

## Using AGI on several devices

To find saved web conversations on another device, sign in with the same account
and choose the workspace you used for the conversation. Check
[Downloads](https://agiworkforce.com/download) before installing another client.
For temporary-chat history and retention, see
[Temporary chats](https://agiworkforce.com/help/temporary-chats).

## CLI provider credentials are separate

Check [surface availability](https://agiworkforce.com/get-started) before using
CLI setup instructions. A bare `agi login` starts AGI managed-cloud sign-in and
does not prompt for a provider API key. For provider-key login and its storage
rules, see [BYOK](https://agiworkforce.com/help/byok-provider-keys).

## Contacting support
