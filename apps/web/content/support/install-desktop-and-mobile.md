## Check current release availability

Check [surface availability](https://agiworkforce.com/get-started) before
installing a client. Use [Downloads](https://agiworkforce.com/download) for the
assets returned by the release service and the platform-specific instructions.

## Installing a desktop client

When a download is offered, choose the asset for your operating system and
processor architecture. Read the download's installation and verification
instructions before opening the file.

For CLI installation, use the [CLI guide](https://agiworkforce.com/cli) after
checking availability. Compare a downloaded archive with its published checksum
before running it.

## What desktop provides

The current Desktop application is managed-cloud-only and does not accept
provider keys or run local models. Read the
[Desktop overview](https://agiworkforce.com/desktop) for supported workflows.
For CLI local inference and provider-key setup, see
[Local mode](https://agiworkforce.com/help/local-mode) and
[BYOK](https://agiworkforce.com/help/byok-provider-keys).

## Mobile

Check the [Mobile page](https://agiworkforce.com/mobile) for current availability.
To use AGI from a phone browser, open [AGI Web](https://agiworkforce.com/chat).

## Before choosing a client

Review the client's setup guide and your [plan](https://agiworkforce.com/pricing).
Check workspace permissions and the operating-system or browser requirements for
the workflow you want to use.
