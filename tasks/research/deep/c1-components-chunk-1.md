## 4. Custom Ink primitives vs raw Ink

Raw-Ink components used directly: `Box, Text, Link, Newline, useInput`. The `'../ink.js'` re-export is the team's curated surface (`Ansi, wrapText, measureElement, type DOMElement, useTerminalFocus, useInterval, Link`).

Custom forks/extensions:

- **`KeyboardEvent`** with `key, ctrl, shift, preventDefault, stopImmediatePropagation` (from `'../ink/events/keyboard-event.js'`). Replaces Ink's primitive `key`-object pattern with React-style synthetic events that propagate up the tree. Used by every Box that needs custom key handling.
- **`useDeclaredCursor({ line, column, active })`** (from `'../ink/hooks/use-declared-cursor.js'`). Parks the native terminal cursor at a specific (line, col) within the ref'd Box. Used for accessibility (screen readers track focus).
- **`useTerminalFocus()`** — terminal-focus events (focus changes between this terminal and others). Used in `BaseTextInput.tsx` to drive `terminalFocus` prop and conditionally show cursor.
- **`useTerminalViewport()`** — returns `[ref, { isVisible }]` for offscreen tracking. Used by `Ratchet`.
- **`stringWidth`** (from `'../ink/stringWidth.js'`) — wide-character-aware width. Used by `Divider` for centered titles.
- **`Ansi` component** — passes ANSI escapes through children unchanged (used by `Divider` for title styling).
- **`wrapText`** — text wrapping helper exposed for callers that compose their own line-wrapped Boxes.
- **`measureElement(ref.current)`** — measures Yoga geometry of a DOM element. Used by `Ratchet`.
- **`ScrollBox`** (from `'../ink/components/ScrollBox.js'`) — virtualized scrolling container used by `Tabs` and elsewhere.
- **`useRegisterOverlay(name)`** (from `'../context/overlayContext.js'`) — registers a component as the active overlay so global handlers like `CancelRequestHandler` skip Escape capture. `BridgeDialog` uses `'bridge-dialog'`; CustomSelect's `useSelectInput` auto-registers when `onCancel` is provided.
- **`useIsInsideModal()` / `useModalScrollRef()`** (from `'../context/modalContext.js'`) — tells `Pane` and `Tabs` to behave differently inside `FullscreenLayout`'s modal slot.
- **`setClipboard(text)`** (from `'../ink/termio/osc.js'`) — OSC 52 clipboard escape. Used by `ConsoleOAuthFlow` and `ExportDialog` to copy URLs/content.

The team has clearly diverged from upstream Ink in non-trivial ways: synthetic-event keyboard, declared-cursor, viewport-aware rendering, and explicit overlay coordination.

## 5. Theme token usage (sampled across chunk)

Theme keys referenced as colors (`color`, `backgroundColor`, `borderColor`):

- **Functional**: `error, warning, success, suggestion, permission, fastMode, promptBorder, inverseText, inactive`
- **Brand**: `claude, chromeYellow, text`
- **Diagnostic**: `ansi:cyan, ansi:red` (raw ANSI bypass), `rgb(...)`, `#hex` (raw)

Most components prefer the **string-keyed theme path** (e.g. `<Text color="error">`) for both functional and brand colors. Raw colors (`rgb`, `#`, `ansi256`, `ansi:`) are bypassed by `resolveColor` at lines 19-23 in `ThemedText.tsx` and `ThemedBox.tsx`. The `feedback-survey` and `agents/ColorPicker` use the explicit raw `ansi:cyan` palette where the color must look the same regardless of user theme.

The user-settable theme palette is `'auto' | 'dark' | 'light'` (and possibly `'high-contrast'` variants), resolved via `ThemeProvider` to a non-`'auto'` value before any render.

## 7. Open observations

- Wizard orchestration (`WizardProvider`, `WizardDialogLayout`, `useWizard`) lives outside this chunk; every step here imports `'../../wizard/index.js'`.
- Keybinding context choice is deliberate: `Settings` in textinput steps so 'n' doesn't cancel typing; `Confirmation` in select-only steps so 'n' ≡ Esc.
- `Feedback.tsx` lines 71-113 own the canonical redaction (re-imported by `submitTranscriptShare.ts`); should be a shared util.
- Multiple `useInput` raw sites carry intentional `'custom-rules/prefer-use-keybindings'` disables for non-configurable keys (Y/N, 'd' for disconnect).
- `FuzzyPicker` is a strong autocomplete/command-palette drop-in.
- `Pane / Dialog / Byline / KeyboardShortcutHint / ConfigurableShortcutHint / ListItem / StatusIcon / Divider / Tabs / LoadingState / ProgressBar / Ratchet` form a tight design-system core.
