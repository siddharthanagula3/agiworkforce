# Where the capability ledger and the feature pages disagree

The project's capability ledger (`audit/ledger/ecosystem-capability-ledger.jsonl`) was audited on 2026-09-26 and updated since. The feature pages were written from the code on 2026-11-24, and a second, cheaper pass then read each page and recorded what it says per app. That pass has its own errors, so treat this page as a list of things to check, not as a list of ledger mistakes. **Spot-check:** 20 of the existence cases were decided from the code by a separate reader: the feature page was right in 14, the ledger in 5, neither or unclear in 1.

| Kind of disagreement | Cases | What it means |
|---|---:|---|
| The page describes it on an app where the ledger says not built | 365 | The ledger may be behind the code |
| The ledger says built or partly built where the page found nothing | 109 | The feature may be gone, or the page's writer did not find it |
| Both say it exists; the page lists unfinished parts where the ledger says built (or the reverse) | 787 | Usually a matter of degree. Not counted as a ledger error. Includes things switched off by decision, such as sales |
| Notes from the area pages that the brief or ledger is out of date | 535 | Free-text notes |

These are kept out of the gap register. Corrections to the ledger go through the project's own process. Machine-readable: [ledger-corrections.json](ledger-corrections.json).
